# Правила игры «Точки»

Изложение своими словами официальных правил ССКТ, утверждённых приказом председателя № 2 от 27.01.2017.
Первоисточник с диаграммами: <https://tensu.ru/rules/>. Номера в скобках — номера статей оригинала.
Если изложение расходится с оригиналом, верен оригинал.

---

## 1. Поле (1.1–1.5)

- Поле состоит из квадратных клеток. Играют на **пунктах** — пересечениях линий.
- Стандартный размер — **39 × 32 пункта** (по горизонтали × по вертикали).
- В официальной записи пункты нумеруются с 1: по горизонтали слева направо, по вертикали снизу вверх.
- Ход записывается как «горизонталь-вертикаль», например `20-17` (2.10).

## 2. Ходы (2.1–2.9, 3.1–3.4)

- Играют двое: **синие** ходят первыми, **красные** — вторыми. Ходы строго по очереди.
- Ход — это постановка своей точки в пункт.
- **Пропустить ход нельзя.** Отменить сделанный ход нельзя.
- Поставленные точки не снимаются с поля до конца партии.
- Нельзя ставить точку:
  - в занятый пункт;
  - в выключенный из игры пункт (см. §4).

## 3. Стартовая позиция (4.1–4.4)

- Партия начинается с **начального скреста**: по две точки каждого цвета в углах одной клетки. Точки одного цвета стоят по одной диагонали.
- Стандартный скрест:
  - синие на `20-17` и `21-16`;
  - красные на `20-16` и `21-17`.
- В переигровках ничьих на соревнованиях можно начинать с **четырёх скрестов**. Они стоят симметрично относительно центра, координаты задают организаторы.

## 4. Окружение (5.1–5.11)

**Цель игры** — окружать точки соперника.

**Цепь окружения** — замкнутая непрерывная ломаная из точек одного цвета. Соседние точки цепи отстоят не более чем на одну клетку: по горизонтали, вертикали **или диагонали**.

**Область окружения** — внутренность замкнутой цепи. Внутри могут быть пустые пункты, любые точки и другие области. В момент замыкания внутри обязательно должна быть **хотя бы одна невыключенная точка соперника** (5.5).
- Минимальная область — четыре точки вокруг одной точки соперника (5.6).

**Что происходит при замыкании цепи** (5.7):
- область закрашивается цветом цепи;
- точки соперника внутри **окружены** (захвачены);
- свои точки и пустые пункты внутри **выключаются из игры**;
- выключенная точка не может входить в цепь (5.7.1);
- в выключенный пункт ставить нельзя никому (5.7.2).

**Дополнительные правила:**
- Граница области может служить частью новых цепей (5.8).
- Если один ход замыкает сразу несколько цепей, получаются **несколько соседних областей**, а не одна общая (5.9).
- **Правило минимальной площади** (5.10). Если цепь можно замкнуть несколькими путями, выбирается путь с наименьшей площадью. Лишние пустые пункты без точек соперника не захватываются.
- Готовую область можно окружить так же, как отдельную точку (5.11). Это **перезахват**, см. §6.

## 5. Домики (5.12–5.16)

**Домик** — замкнутая цепь вокруг пространства, где есть только пустые пункты и/или свои точки, но **нет точек соперника**.
- Домик не закрашивается и не рисуется.
- Пункты и точки внутри домика из игры **не выключаются** (5.13).

**Ход соперника внутрь домика:**
- Соперник может поставить точку в чужой домик только один раз (5.14).
- Как только ход переходит к хозяину домика, эта точка считается окружённой. Домик закрашивается и становится областью окружения.
- Если внутри чужого домика окружены свои точки, действует правило минимальной площади (5.15).

**Исключение (5.16).** Точка, поставленная в чужой домик, **не окружается**, если сама замыкает цепь своего цвета. Она становится частью новой области своего цвета, и эта область включает часть бывшего домика.

## 6. Счёт (6.1–6.5)

- **Начисление.** За каждую окружённую точку соперника — одно очко (6.1). Это касается и одиночных точек, и точек внутри ранее созданных областей любого цвета.
- **Изменение счёта.** Текущий счёт меняется после каждого хода, который создаёт область (6.3).
- **Перезахват** (6.4). Если игрок B окружил область игрока A:
  - область A считается утраченной;
  - точки A внутри новой области (включая бывшую границу и выключенные свои точки A) идут в зачёт B;
  - очки A за точки B, которые были в этой области, **вычитаются** из счёта A.
- **Итог.** Текущий счёт на момент окончания партии становится итоговым (6.5).

## 7. Время (7.1–7.2)

У обеих сторон одинаковый запас времени. Кто исчерпал его, проигрывает. Систему отсчёта задают организаторы.

## 8. Окончание партии (8.1–8.6)

Партия заканчивается в одном из случаев:

| Случай | Результат |
|---|---|
| а) сдача | поражение сдавшемуся, счёт на результат не влияет |
| б) истекло время | поражение тому, у кого истекло, счёт не влияет |
| в) на поле нет пустых пунктов | решает итоговый счёт |
| г) объявлено **заземление** | применяется 8.4, затем решает итоговый счёт |
| д) ничья по соглашению | счёт не влияет; соглашение нельзя отозвать (8.5) |

**Заземление** (8.2–8.4):
- Это конфигурация групп точек и областей игрока, которую **невозможно окружить**. Причины три: края поля, непрерывность цепи и правила хода в домик.
- Объявить заземление можно один раз, отозвать нельзя.
- После объявления все **свои** точки, группы и области, которые ещё можно окружить, считаются окружёнными соперником. Их очки добавляются к счёту соперника.

**Победа** (8.6). Побеждает тот, у кого больше очков хотя бы на одно. При равенстве — **ничья**.

## Как правила отражены в движке KataGoDots

| Правило | Движок |
|---|---|
| Поле 39 × 32 | размер по умолчанию при `DOTS_GAME=1`. Координаты движка 0-based: `x ∈ [0, x_size)`, `y ∈ [0, y_size)` |
| Синие ходят первыми | `P_BLACK` = синие |
| Стандартный скрест | правила `bbs` (`START_POS_CROSS`, не случайный) |
| Четыре скреста | правила `notago` (`START_POS_CROSS_4`, случайный сдвиг) |
| Пропуск хода запрещён | `PASS_LOC` означает только **заземление**, а не пас |
| Заземление (8.2–8.4) | `whiteScoreIfGroundingAlive`; доска инкрементально ведёт `blackScoreIfWhiteGrounds` / `whiteScoreIfBlackGrounds` |
| Ход в чужой домик (5.14) | разрешён при `multiStoneSuicideLegal = true`; при `false` такие ходы отсекаются, кроме случая 5.16 |
| Обязательная точка соперника внутри области (5.5) | стандарт. Опция `dotsCaptureEmptyBases` — нестандартное расширение (окружение пустых баз) |
| Угловые пункты | движок исключает их из разумных ходов: «никогда не выгодны» (`dotsboardhistory.cpp`) |
| Время | в GTP есть задержка Бронштейна; это настройка организаторов (7.2), а не часть правил |
